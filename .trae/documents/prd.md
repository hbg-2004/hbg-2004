
# 家具装修攻略网站 - 产品需求文档

## 1. 项目概述

### 1.1 项目背景
随着人们对居住环境品质要求的提高，家具装修成为越来越多人关注的话题。本网站旨在为用户提供专业、实用的家具装修攻略，帮助用户轻松打造理想家居空间。

### 1.2 目标用户
- 准备装修或正在装修的业主
- 对家居设计感兴趣的爱好者
- 寻求装修灵感和建议的普通用户

### 1.3 核心价值
- 提供全面的装修攻略和设计灵感
- 帮助用户了解装修流程和注意事项
- 分享实用的装修技巧和经验

---

## 2. 功能需求

### 2.1 首页
- 展示热门装修攻略卡片
- 分类导航（按房间类型）
- 精选案例展示区
- 搜索功能

### 2.2 攻略分类
- 客厅装修攻略
- 卧室装修攻略
- 厨房装修攻略
- 卫生间装修攻略
- 书房装修攻略
- 儿童房装修攻略

### 2.3 攻略详情页
- 攻略标题和封面图
- 详细内容（图文并茂）
- 相关攻略推荐
- 收藏/分享功能

### 2.4 装修风格展示
- 现代简约风格
- 北欧风格
- 中式风格
- 日式风格
- 轻奢风格

### 2.5 装修案例
- 实景案例图片展示
- 案例详情介绍
- 装修预算参考

---

## 3. 设计要求

### 3.1 视觉风格
- 温暖舒适的色调
- 简洁现代的布局
- 高质量图片展示
- 响应式设计

### 3.2 色彩方案
- 主色调：温暖木色系（#8B7355）
- 辅助色：米色、浅灰色
- 强调色：绿色植物色

### 3.3 交互体验
- 平滑滚动效果
- 卡片悬停动画
- 图片懒加载
- 导航栏滚动变化

---

## 4. 技术要求

- 框架：Vue 3 + TypeScript
- 构建工具：Vite
- 样式：Tailwind CSS 3
- 路由：Vue Router
- 状态管理：Pinia
- 图标：Lucide Icons

---

## 5. 部署要求

- 部署平台：Vercel
- 构建命令：npm run build
- 输出目录：dist
